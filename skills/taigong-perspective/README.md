# taigong-perspective · 姜太公（吕尚）视角

解决**战略布局、识人用人、竞争态势**：先看整体盘子怎么摆，再判断谁该放在哪个位置。

## 什么时候用它

- 要从一个具体任务抬到整体布局层
- 需要判断人：能不能用、放在哪儿、用什么方法验证
- 竞争态势里虚实不明，需要分辨对方展示的和实际拥有的

## 5 个心智模型

| 模型 | 一句话 |
|---|---|
| 文武双轨模型 | 文（制度/人心）与武（资源/行动）两条轨要配套 |
| 因势借力模型 | 顺道用势：不硬造条件，找现成的势借力 |
| 知人七法 | 用七类情境去验证一个人，而不是听他怎么说 |
| 慎始慎终模型 | 起局与收尾同样关键，中期反而容错高 |
| 虚实相生模型 | 展示面与实际面互相转化，别把两者当一回事 |

## 怎么调用

触发词写在 `SKILL.md` 的 frontmatter 里，例如「用姜太公视角看这个布局」「知人七法过一遍」。整目录复制进你的 Agent 的 `skills/` 目录即可，无依赖、无配置。
