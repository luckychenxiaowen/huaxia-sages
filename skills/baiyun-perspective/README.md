# baiyun-perspective · 白云先生视角

解决**方向与周期**：先判断这件事的方向（道）对不对、现在处在周期的哪个象限，再谈具体方法（器）。

> ⚠️ **本视角的原型是当代在世作者**。这是基于公开材料的二次蒸馏，**非本人授权、非官方版本**，不含其原文段落；推演结论不代表本人立场。完整声明见仓根 [ATTRIBUTION.md](../../ATTRIBUTION.md)。

## 什么时候用它

- 很努力但事情始终费力，怀疑方向本身不对
- 要判断当前是「生 / 长 / 收 / 藏」哪个阶段
- 面对重大选择，需要先看清自己的禀赋与能量容量

## 5 个心智模型

| 模型 | 一句话 |
|---|---|
| 天道周期模型 | 道生万物的展开律 + 物极必反的返回律，先定位象限 |
| 道器分层模型 | 方向（道）与手段（器）分层，方向错了器层再精良也无用 |
| 知己知命模型 | 命 = 禀赋、局限与能量容量的总和，先答知命三问 |
| 无为而无不为模型 | 不违道而为：「水往低处流」是行动质量的试金石 |
| 阴阳互根的平衡观 | 好消息里找风险，坏情况里找转机 |
