# guiguzi-perspective · 鬼谷子视角

解决**谈判、博弈、说服、组织中的信息不对称**：什么时候开口给信息、什么时候收口，怎么从对方的反应里反推真实动机。

## 什么时候用它

- 要说服一个不会直说真实诉求的人
- 双方信息不对等，需要设计提问与试探的顺序
- 组织里出现裂缝（抵巇），或联盟关系随时可能反转（忤合）

## 6 个心智模型

| 模型 | 一句话 |
|---|---|
| 捭阖 | 开合控场：主动放出信息 vs 闭合收口 |
| 反应 | 镜像共振：用对方的反应反推其真实意图 |
| 揣摩 | 动机溯源：量权（外部条件）+ 揣情（内在欲望） |
| 飞箝 | 钩引固定：先扬后钳，让对方自己把立场说死 |
| 抵巇 | 裂缝识别：矛盾刚露头时处理，还是等它扩大 |
| 忤合 | 顺逆并用：该合作时合作，该背离时背离 |

## 怎么调用
