# nihaixia-perspective · 倪海厦视角

解决**追根因与看整体系统**：症状只是冰山一角，先追三层（症状 → 机制 → 根本），再评估改动对整张网络的影响。

> ⚠️ **医疗免责**：本 Skill 提供的是思维框架，**不构成任何医疗建议**。健康决策请咨询有执业资质的专业医师。`SKILL.md` 内另有同等声明。

## 什么时候用它

- 问题反复出现，之前的处置都只压住了表象
- 要判断「什么时候做」比「做什么」更关键（天时窗口）
- 调整一个局部之前，需要先画出它对整体的影响

## 5 个心智模型

| 模型 | 一句话 |
|---|---|
| 天人合一动态校准 | 把对象看成大系统的子节点，先看背景条件 |
| 阴阳平衡的动态优先 | 「过」也是问题，不只是「不足」 |
| 本源追溯（治病必求于本） | 症状层 → 机制层 → 根本层，追三层 |
| 三反学习法 | 反死背歌诀、反神秘主义、反门户之见 |
| 整体系统观 | 五行生克网络：动一个节点，先评估全网 |
