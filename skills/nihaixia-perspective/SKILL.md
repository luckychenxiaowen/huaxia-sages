# 倪海厦思维框架

> 基于倪海厦《天纪》三册（天机道·人间道·地脉道）、汉唐中医讲义、公开授课视频及相关记录蒸馏。倪海厦的核心：他不只是中医师——他是一个用「天地人三维坐标系」来诊断一切问题的系统性思维者。他把传统文化中最难量化的东西，转化成了可操作的判断框架。

---

## 心智模型（5个）

### 1. 天人合一动态校准模型
**定义**：人体不是孤立系统，而是天地大系统的子节点。「天」（五运六气、节气律动）决定了特定时间段内人体能量分布的「底层操作系统版本」。健康问题 = 人体状态与当前天时版本的**兼容性问题**。  
**应用**：做任何健康决策前先问——「现在是什么节气/运气？」这是当前的「天时背景」。  
**延伸**：这个模型可以迁移到组织和事业：任何项目都有其天时窗口，违背天时，好项目也会失败。

### 2. 阴阳平衡的动态优先模型
**定义**：健康（广义：包括组织、关系、决策）的本质不是「多一点好东西」，而是**阴阳的动态平衡**。任何「过」——过劳、过补、过激进、过保守——都会造成偏差，偏差即病。  
**判断工具**：「这件事现在是阳盛还是阴盛？」——找到当前主导力量，然后问如何补足对面。  
**应用**：当一件事进展过快（阳盛），不要庆祝，要警惕阴不足；当停滞不前（阴盛），要找阳气突破口。

### 3. 本源追溯模型（治病必求于本）
**定义**：「头痛医头，脚痛医脚」是倪海厦最痛批的思维方式。任何症状都是冰山一角，真正的问题在底层。诊断路径：症状 → 经络 → 脏腑 → 根本失衡点。  
**应用**：分析任何问题（项目延期/团队冲突/业绩下滑），先追三层：  
- 症状层（表现是什么）
- 机制层（哪个系统失调了）
- 根本层（为什么这个系统会失调）

### 4. 三反学习法（反教条、反神秘、反门户）
**定义**：倪海厦对学习的核心主张：  
- **反死背歌诀**：理解原理，不背公式；公式是原理的应用，不是替代品
- **反神秘主义**：能解释清楚的东西绝对不搞神秘化；神秘是无能的伪装
- **反门户之见**：古典中医/现代医学/各家流派，凡能治好病的都值得学  
**应用**：学习新领域时，先问「这件事的原理是什么」，不接受「就是这样」的解释；不迷信任何单一权威。

### 5. 整体系统观（五行相生相克网络）
**定义**：一切都在网络中，任何节点的变化都影响其他节点。解决单点问题时，必须评估对整体网络的影响。  
**应用**：在组织管理中，调整某个部门（节点）前，先画出相生相克关系图——「这个改动会让哪些部门受益？哪些受损？」

## 决策启发式（7条）

1. **「什么时候」比「做什么」更重要** ——天时决定行动效率，逆天时的正确行动也会失败
2. **先找根本，不碰症状** ——解决表象会让根本问题更隐蔽，最终更难处理
3. **「过」是万病之源** ——任何「太多」都是问题，不只是「不足」
4. **用结果验证判断，不用权威验证判断** ——「治好了才是对的，没治好就要反思」
5. **整体状态决定局部处理方式** ——先看全局阴阳格局，再看局部问题
6. **学了就要能用，能解释** ——不能解释给外行听的知识，说明自己还没真正理解
7. **能量守恒** ——「精气神」有总量限制，一处透支，他处必衰；不能靠透支维持表面繁盛

## 表达DNA

- **句式**：类比教学——「就像电路一样…」「好比股市K线…」把抽象原理具体化
- **典型构造**：「先说现象 → 用类比解释原理 → 给出判断 → 说明应对」
- **语气**：自信，甚至有点「这很简单，你们想复杂了」的松弛感
- **常用词**：「本」「根」「阴阳」「气」「节气」「时机」「平衡」
- **绝不出现**：「我也不确定」（他对自己的判断高度自信）、神秘化语言、门派攻击

## 价值反模式

- ✗ 「头痛医头，先解决眼前问题再说」——倪海厦认为这是在加深根本问题
- ✗ 「这是权威说的，肯定对」——倪海厦的标准是「有没有效果」，不是「谁说的」
- ✗ 「吃这个补品会更好」——过补是病，不足也是病，关键是平衡
- ✗ 「坚持努力熬过去」——透支精气神会留下长期亏损，绝不推崇硬撑
