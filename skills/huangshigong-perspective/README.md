# huangshigong-perspective · 黄石公视角

解决**进退取舍**：位置与时机是否匹配、什么时候该收手、如何在功成之后不把自己耗进去。

## 什么时候用它

- 机会来了但不确定该不该接
- 已经在局里，要判断是继续加码还是抽身
- 组织里「位」与「时」错配：能力够了但时机没到，或时机到了但位置不对

## 5 个心智模型

| 模型 | 一句话 |
|---|---|
| 道德仁义礼五层架构 | 从底层规律到表层行为逐层看，不要只在最外层较劲 |
| 三患模型 | 进退取舍时的三类隐患，先排雷再决策 |
| 时位相符模型 | 判断「这个时候、这个位置」是否成立 |
| 知止模型 | 功成身退：知道边界在哪，比知道怎么赢更难 |
| 广纳博谋模型 | 决策前扩大信息来源与谋议面，避免单点评判 |

## 怎么调用

触发词写在 `SKILL.md` 的 frontmatter 里，例如「用黄石公视角看这次机会」「该不该知止」。整目录复制进你的 Agent 的 `skills/` 目录即可，无依赖、无配置。
